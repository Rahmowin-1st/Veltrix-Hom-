# Scientific Calculator Capability Matrix

Canonical source: `ExpressionEngine.kt` + `scientific-calculator`.
Implemented: arithmetic, unary signs, parentheses, power, factorial/percent, constants pi/e/tau/phi, trig/inverse trig DEG/RAD, hyperbolic functions, roots, logs/exp, abs/floor/ceil/round/min/max, structured domain/divide-by-zero/non-finite errors.
Arbitrary-precision transcendental and general complex-valued scientific functions are not claimed by this mode; complex capabilities are separate tools.
