# Subject Library / Tool Registry Contract

The canonical machine-readable export is generated by the verified core test run as `core/build/registry-export.tsv`.

Each `ToolDefinition` includes stable id/title/subject/category/topic/description, aliases/misspellings/keywords/tags, environment and executor family, structured input/output schemas, formula/validation/unit/graph metadata where relevant, related tools, widget/compact capability, history/offline/live-data policies, and schema version.

Converters are intentionally absent from the Library registry and live in `ConversionRegistry`.

## Subject coverage
- **Math**: standard/scientific, number/arithmetic, algebra/equations/polynomials, matrices/vectors, complex, calculus, combinatorics/probability-oriented numeric tools.
- **Physics**: motion, force/momentum/impulse, work/energy/power, pressure/density, torque, waves, electricity, heat, optics numeric relations.
- **Geometry**: triangles including ambiguous SSA handling, quadrilaterals/polygons, circle/sector/arc/ellipse, prism/cube/cuboid/cylinder/cone/sphere, coordinate geometry.
- **Chemistry**: molar mass/composition, mass-moles, concentration/molarity/dilution, solution density, ideal gas, stoichiometric mole ratio.
- **Statistics**: dataset summary and discoverable mean/median/mode/range/variance/stddev/weighted mean/percentile tools.
- **Finance**: change/discount/tax/markup/margin, interest, loan, tip, split bill.
- **Computer**: programmer calculator contracts.
- **Date & Time**: date difference, duration arithmetic, age.
- **Text / Language**: deterministic text counts + OCR analysis contract.
