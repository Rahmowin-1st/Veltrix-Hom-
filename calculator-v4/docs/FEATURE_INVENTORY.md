# Complete Feature Inventory

## Core modes
- Standard Calculator: precedence, parentheses, decimal/negative/percent arithmetic, powers/roots through deterministic expression engine.
- Scientific Calculator: trig, inverse/hyperbolic functions where engine-supported, degree/radian settings, logs, exponentials, factorial/constants/scientific notation.
- Programmer Calculator: BIN/OCT/DEC/HEX parsing/output, bitwise operations/shifts, 8/16/32/64-bit width and explicit signed/unsigned overflow semantics.

## Library subjects
Math; Physics; Geometry; Chemistry; Statistics; Finance; Computer; Date & Time; Text / Language.

## Major purpose-built families
Structured linear/quadratic/cubic/quartic/higher polynomial solving; Vieta; Discriminant; polynomial roots/division; systems; complex arithmetic; matrix/vector; calculus; number/combinatorics/sequences; Physics formula solvers; triangle/coordinate/shape Geometry; Chemistry numeric tools; Statistics; Finance; Date/Time; OCR/Text Analyzer; dedicated Graph tools.

## Independent systems
Standalone converters; live currency; Mega Search; Adaptive Engine; Unified History; AppWidget micro-tools; OCR scanner; resizable/multi-window lifecycle foundation.

## Explicit exclusions
No generative AI, chatbot, Smart Calculator, Continue, recommendation feed, trading dashboard, custom overlay window, draw-over-other-apps permission, or cloud dependency for core calculations.
